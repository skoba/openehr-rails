### 上流への問い(文面の案。投稿はこのセッションでは行わない)

> AQL: `c/context/start_time/value` raises `unsupported path attribute "start_time" on a
> OpenEHR::RM::Composition::EventContext` whenever the composition has a context (openehr 2.4.3;
> `path_evaluator.rb` `navigate_terminal`). `EventContext` is not PATHABLE and declares no path attributes,
> and `ALLOWED_TERMINAL_HOPS` has only `magnitude`, `name`, `value`. Reproduction: build a `Composition`
> with `context: EventContext.new(start_time:, setting:)`, run
> `SELECT c/context/start_time/value FROM EHR e CONTAINS COMPOSITION c`. Expected: the ISO 8601 value.
> Same for `c/context/setting/value` and `c/context/setting/defining_code/code_string`.
> Does 2.5.0 (#48 / #49) cover EVENT_CONTEXT, or is this a new issue for 2.5.x / 2.6.0?
